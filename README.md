# 🚑 AI ER Triage Assistant

Aplikasi Sistem Pendukung Keputusan (DSS) berbasis Generative AI untuk membantu tenaga medis di Instalasi Gawat Darurat (IGD) menentukan level Triase dan Disposisi ruangan pasien secara cepat.

## Fitur
- Analisis Keluhan Klinis & Tingkat Kesadaran
- Analisis parameter lab krusial (Darah Rutin & Gula Darah)
- Output Triase (Merah, Kuning, Hijau, Hitam) & Disposisi (ICU, HDU, Rawat Inap, Rawat Jalan)
- Ditenagai oleh Google Gemini API

## Teknologi
- Python
- Streamlit
- Google Gemini API
